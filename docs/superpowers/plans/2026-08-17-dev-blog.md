# Parker's Dev Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a bilingual (zh default / en) static software-dev blog with Markdown content, cyan/pixel dark-mode-first theming, tags, TOC, giscus comments, and RSS, deployed to Cloudflare Pages at `dev.parkerchang.life`.

**Architecture:** Astro static site (no server adapter). Markdown lives in Astro Content Collections under `src/content/posts/{zh,en}/`. Pure data-shaping logic (slugs, reading time, sorting, tag dedupe) lives in a dependency-free `src/lib/post-utils.ts` so it's unit-testable; collection-querying wrappers live in `src/lib/posts.ts` and are verified via `astro build`/dev-server checks since they depend on the `astro:content` virtual module. Pages are duplicated per locale (`src/pages/...` for zh, `src/pages/en/...` for en) but share Astro components.

**Tech Stack:** Astro (static output), Tailwind CSS + `@tailwindcss/typography`, `@astrojs/rss`, Vitest for unit tests, giscus for comments, Cloudflare Pages for hosting.

## Global Constraints

- Site title: "Parker's Dev Blog".
- Default locale is zh (routes with no prefix); English routes are prefixed `/en/`.
- Content lives at `src/content/posts/zh/<slug>.md` and `src/content/posts/en/<slug>.md`; translation pairing is by matching slug, and a translation is optional.
- Frontmatter fields: `title`, `description`, `pubDate`, `updatedDate?`, `tags: string[]`, `draft?: boolean`.
- Primary accent color is cyan; dark mode is the primary visual identity, defaulting to `prefers-color-scheme`, overridable and persisted in `localStorage`.
- Pixel font ("Press Start 2P") is used only for the site title/large headings, never body text.
- Comments via giscus backed by GitHub Discussions on `Parkerhiphop/dev-blog`.
- Deploy target: Cloudflare Pages, custom domain `dev.parkerchang.life`, build command `npm run build`, output dir `dist`.
- Footer links to `https://www.parkerchang.life` and `https://github.com/Parkerhiphop`.
- No search, no multi-author, no CMS/admin UI.

```ts
export type Lang = 'zh' | 'en';

export function getLangFromId(id: string): Lang {
  return id.startsWith('en/') ? 'en' : 'zh';
}

export function getSlugFromId(id: string): string {
  return id.split('/').slice(1).join('/');
}

export function getReadingTimeMinutes(body: string, lang: Lang): number {
  if (lang === 'zh') {
    const charCount = body.replace(/\s/g, '').length;
    return Math.max(1, Math.round(charCount / 400));
  }
  const wordCount = body.trim().split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(wordCount / 200));
}

export function sortByDateDesc<T extends { data: { pubDate: Date } }>(items: T[]): T[] {
  return [...items].sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
}

export function dedupeSortedTags(tagLists: string[][]): string[] {
  const set = new Set<string>();
  for (const tags of tagLists) {
    for (const tag of tags) set.add(tag);
  }
  return Array.from(set).sort();
}
```

- [ ] **Step 1: Implement `src/lib/posts.ts`**

```ts
import { getCollection, type CollectionEntry } from 'astro:content';
import {
  type Lang,
  getLangFromId,
  getSlugFromId,
  sortByDateDesc,
  dedupeSortedTags,
} from './post-utils';

export type Post = CollectionEntry<'posts'>;

export async function getPostsByLang(lang: Lang): Promise<Post[]> {
  const posts = await getCollection(
    'posts',
    ({ id, data }) => getLangFromId(id) === lang && !data.draft,
  );
  return sortByDateDesc(posts);
}

export async function getTranslationSlug(post: Post): Promise<string | null> {
  const otherLang: Lang = getLangFromId(post.id) === 'zh' ? 'en' : 'zh';
  const slug = getSlugFromId(post.id);
  const candidates = await getPostsByLang(otherLang);
  const found = candidates.find((p) => getSlugFromId(p.id) === slug);
  return found ? slug : null;
}

export async function getAllTags(lang: Lang): Promise<string[]> {
  const posts = await getPostsByLang(lang);
  return dedupeSortedTags(posts.map((p) => p.data.tags));
}

export async function getPostsByTag(lang: Lang, tag: string): Promise<Post[]> {
  const posts = await getPostsByLang(lang);
  return posts.filter((p) => p.data.tags.includes(tag));
}

export function postHref(post: Post): string {
  const lang = getLangFromId(post.id);
  const slug = getSlugFromId(post.id);
  return lang === 'en' ? `/en/posts/${slug}/` : `/posts/${slug}/`;
}
```

  const root = document.documentElement;
  const icon = document.getElementById('theme-toggle-icon')!;

  function applyTheme(theme: 'light' | 'dark') {
    root.classList.toggle('dark', theme === 'dark');
    icon.textContent = theme === 'dark' ? '☀️' : '🌙';
  }

  function currentTheme(): 'light' | 'dark' {
    return root.classList.contains('dark') ? 'dark' : 'light';
  }

  document.getElementById('theme-toggle')?.addEventListener('click', () => {
    const next = currentTheme() === 'dark' ? 'light' : 'dark';
    localStorage.setItem(STORAGE_KEY, next);
    applyTheme(next);
    window.dispatchEvent(new CustomEvent('theme-change', { detail: next }));
  });

  applyTheme(currentTheme());
</script>
